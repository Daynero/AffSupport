## Catalog output destination

Both catalog creation and automatic updates resolve the connected root's `Soty Cache/Restitched`. Catalog creation passes that material as `destinationFolderId` to processing. A marked legacy Restitched folder directly under the connected root is moved into the cache while retaining its Drive ID. A folder belonging to another root is not adopted. Catalog creation fails if the cache cannot be resolved, rather than writing beside the source video. This behavior is already present at the release tag; no code change is necessary for the requested destination.
