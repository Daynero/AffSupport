# Soty design rules (дизайн-система)

Оунерський орієнтир: лакшері мінімалізм, як в Apple. Менше тексту, більше
іконок; слова живуть у тултіпах. Еталон: блок «Заповнення кадру» +
«Тривалість початкового зображення» (picto-група, маленьке інлайн-поле,
суфікс «мс»).

## Іконки
- Джерело: **lucide-react** (ISC). Ніяких саморобних SVG.
- Розмір за замовчуванням: `ICON_SIZE = 20`, `ICON_STROKE = 1.75`
  (константи в `apps/web/src/components/icons.tsx`).
- Комфортне правило: 20px — комфортний розмір іконки. Якщо тісно —
  **збільшуй підложку (кнопку/плитку), ніколи не зменшуй іконку**.

## Picto-групи (вибір одного з кількох)
- Розмітка: `<div class="fit-mode-pictos" role="radiogroup">` з
  `<button role="radio">` всередині.
- Кнопка: 44×38, іконка по центру; варіант з текстом — клас `is-labeled`
  (цифри/короткі значення: `24`, `1080p`, `30–40`).
- Вибраний стан: клас `is-selected` (акцентна рамка + 16% заливка).
  НЕ `is-active` — такого класу в системі нема.
- Контейнер: рамка + 4px padding + 6px gap, `width: fit-content` — без
  порожньої полиці за кнопками.
- Одиночний тогл (checkbox-поведінка): той самий button, але контейнер
  з класом `is-single` — рамка контейнера зникає, лишається одна кнопка
  (подвійна обводка = помилка).
- У кожної кнопки `title` + `aria-label` (тултіп замість підпису).

## Інлайн-поля вводу
- Кастомне значення поруч із picto-групою, в одному ряду
  (`.start-duration-row`): обгортка `.input-with-suffix` →
  `<input class="time-input">` + `<span>` із суфіксом (`мс`, `px`, `fps`,
  `kbps`).
- Ширина 72–150px (96px для чисел, 150px для тексту типу суфікса назви).
  Ніколи не на всю колонку.
- Підпис одиниці — **за межами рамки інпуту**, muted-текст поруч
  (еталон — «мс»). Ніколи не всередині поля.
- number-інпути без браузерних спінерів (клацалки прибрані глобально) —
  значення вводяться з клавіатури.
- Текстове поле теж може стояти прямо в ряду з picto-групами
  (клас `suffix-input`), з `title`-тултіпом замість підпису.

## Валідація
- Помилку показуємо ТІЛЬКИ після невалідного вводу. Порожнє щойно
  відкрите поле — не помилка (`&& custom !== ''` в умові показу).
- Невалідний стан: клас `is-invalid` на полі + `.field-error` під рядом
  через `Collapse fast`.

## Ряди і компоновка
- Групи налаштувань — ліві «полиці»: `flex-wrap`, спільний gap
  (`var(--space-4) var(--space-6)`), кожна група шириною зі свій вміст.
  Ніяких напівпорожніх grid-колонок.
- Група = `FieldLabel` (назва + «?»-тултіп) над контролом.
- Пояснювальні фрази («Цей кадр додається до кожного відео…») — у
  тултіп поля, не постійним текстом.

## Колір і стани
- Вибране/активне: акцентний фіолет (`--color-accent`).
- Активні плитки зображень: зелене «лакшері» свічіння
  (outline 1px color-mix 55% + м'який box-shadow glow, #34c759).
- Неактивні плитки: сірий veil 20% на всю плитку + grayscale/blur,
  великих хрестів нема.
- Функціональні кнопки: деструктивні — червоні, позитивні (скачати,
  зберегти) — зелені.
- Прогрес вручну: зелений ліворуч, червоний праворуч; ніколи не
  скидається автоматично.

## Кнопки дій
- Квадратні плейти для іконкових дій: 30×30 (плитки) або 44×38 (ряди).
- `+` і `×` — лише lucide `Plus`/`X`, той самий розмір, словами не
  підписуємо (слова в `title`).
