# Quickstart: перевірка 062 на беті

Передумови: бета піднята (див. пам'ять про холодний старт), міграції 062 накатані через psql + `schema_migrations` (не `migration up`, не `db reset`). Простір для запису — тестова папка в Goor або фікстурний простір беті.

## 1. Кілька відео без перезашивки (US1, US2)

1. Запуски → новий → метод «Каталог».
2. Кинути 4 відео одним жестом → 4 рядки в полі креативу.
3. «Товарів у каталозі» = 100 → з'являється «Розподіл між креативами · 25 · 25 · 25 · 25».
4. Розгорнути, перший повзунок → 40: інші 20/20/20. Далі через поля: першому 40, другому 30 → 40/30/15/15; третьому 20 → 40/30/20/10.
5. Змінити 100 → 200: 80/60/40/20. «Порівну»: 50×4. Повернути 100 і 40/30/20/10.
6. Перезавантажити сторінку — розподіл збережено.
7. Згенерувати. У каталозі: 4 блоки 40/30/20/10 у порядку, ID `<alias>-…`, у кожному блоці посилання лише на своє відео.

## 2. Варіації (US3)

1. Той самий запуск, перезашивка увімкнена, варіації 30 при 25×4 → підказка `8 · 8 · 7 · 7`.
2. Варіації 3 → помилка «щонайменше 4».
3. Згенерувати (агент онлайн) → 4 набори, 30 файлів; різниця товарів між варіаціями одного відео ≤ 1.

## 3. Зображення (US4, US5)

1. Новий каталожний запуск, 3 зображення JPEG/PNG ≥ 500 px, 90 товарів.
2. Перемикача перезашивки й розкладу немає.
3. Спробувати кинути відео → відмова з поясненням, список без змін.
4. Згенерувати → 3 блоки по 30; `image_link` = `https://…/c1/<uuid>`, `curl -sI` без cookies → 200, `image/jpeg`; колонки Z/AA порожні; назви «… Catalog Item».
5. Лічильники загального пулу білих не змінились (SQL-запит по `catalog_global_*` до/після).

## 4. Пакет і копіювання (US6)

1. Виділити запуск з 4 креативами, Cmd+C, Cmd+V ×3 → 3 чернетки з тими самими креативами й розподілом.
2. «Згенерувати вибрані» → 3 каталоги, кожен 40/30/20/10.
3. Картка показує `alias +3` і значок відео.

## 5. Оновлювач

Запустити плановий update каталогу з п.1 і каталогу з п.3 (`catalog-updater` вручну). Запустити оновлення двічі. Блоки, префікси й тип збережені; у менеджері каталогів «Замінити відео» прихована; у каталозі зображень — ті самі `c1/` посилання, порожні відео-колонки.

## 6. Аналітика

`npm run analytics -- inspect launch <id>` (див. AGENTS.md) — видно `creativeKind`, `creativeCount`, стадії `creative_image.*`; для штучно зламаного одного відео — `failedOrdinal`.

## 7. Регресія

Старий запуск з одним відео: відкрити, скопіювати, перегенерувати — працює; новий каталог має префікс, старий каталог при оновленні — без префікса.
