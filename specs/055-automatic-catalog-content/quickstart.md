# Validation guide

Use the isolated055worktree and serial checks. No production configuration writes or pool activation.

1. Run the shared content tests: all32 categories, neutral unknowns, exactly2,000 unique selections, exhaustion, random boundaries and bounds.
2. Run creation/Launch full-chain SQL regressions: no settings, old accepted intent, old frozen resources, new automatic revision, lost acknowledgment/retry, changed source and cancellation.
3. Run updater regressions: final image-first pairing, growth with retained manual rows, refresh combinations, proved-unchanged retry, unknown write, stale lease, new attempt and bounded recipe replacement.
4. Run SQL→CLI diagnostic regressions for creation and updates, unavailable global pool, missing/invalid policy evidence and absent browser result signal. Assert private content never reaches output.
5. Run desktop settings/creation/manager route tests; verify no catalog reads/implicit writes and old bookmarks open manager. Capture desktop settings and representative generated rows using the existing local fixture harness.
6. Measure100 independent200-row generations and report p95 with host/runtime and exclusions.
7. Run `npm run verify` and applicable build/database groups. The local DB runner uses an owned disposable schema/roles-only clone; never a remote target. Record exact source, actual totals/skips/failures and any release acceptance still pending.
8. Integrate completed055and independent completed fixes into `integration/next-release-2026-11-13`. Keep main/beta, versions, tags, signed manifest and deployed channels unchanged.
