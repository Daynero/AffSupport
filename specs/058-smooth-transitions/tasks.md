## Відгук власника після кліків (2026-11-18) — знахідки й фікси

Власник: «все різке як і було, скелетони стрибають»; далі «ефект є, але замало: між вкладками щось перебудовується, щось змінює розмір, контент різко з'являється; Запуски з масовим прогресом блимають, провідник без скелетонів блимає». Попередній смок цього не бачив: миттєва заміна кадру має excess ≈ 1, і жоден кадр не порожній.

| Знахідка                                                                  | Причина                                                                                            | Фікс                                                                                                 |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Кожен клік — обрив замість переходу                                       | кожен `useBrowserRoute` сам комітив навігацію: 4 view transitions на клік, кожна скіпала попередню | один роутер на всіх читачів адреси, один коміт                                                       |
| Через 2–3 переходи анімація зникає                                        | `lite` рахував довгий кадр рендеру перед анімацією                                                 | кадри від `ready`; lite — 3 анімації поспіль по ≥2 довгих кадри                                      |
| Перехід читається як різка зміна кадру                                    | 150 мс на крутій ease-out                                                                          | 300/220 мс, ease-in-out                                                                              |
| Скелетон маршруту → скелетон даних → вміст                                | новий екран показувався одразу                                                                     | перехід тримає старий екран до 350 мс, поки в новому є `aria-busy`/скелетон                          |
| Запуски: порожня рамка, «запусків немає», картки, блок пакетів — по черзі | вкладка не зберігалась між візитами, частини читались незалежно                                    | `Activity` (живе приховано, без опитування); `Reveal` чекає список, словники й перше читання пакетів |
| Тека у плитках: скелетон рядків → плитки                                  | форма заготовки не та                                                                              | плитки замість рядків; тека — `section`-перехід з утриманням                                         |
| Учасники / журнал блимають від живих оновлень                             | повторне читання ховало список за скелетоном                                                       | заготовка лише до першого читання                                                                    |
| Смок не ловив «різку появу»                                               | метрика лише на порожні кадри                                                                      | метрика `pop`: частка всього руху в одному кадрі; новий перехід «open a folder»                      |
| Бета — dev-збірка: важкі вкладки замерзають і стрибають                   | React dev у рази повільніший                                                                       | бета для власника — прод-збірка (`vite build --mode beta` + preview)                                 |
