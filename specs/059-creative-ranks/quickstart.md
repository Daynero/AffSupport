# Quickstart — перевірка 059

Машина слабка: перед кожним кроком `uptime` і `pgrep -fl "tsc|vitest|vite build"`; vitest лише
single-worker. Міграцію на бету — через psql + запис у `schema_migrations` (`migration up` заблоковано),
ніколи `db reset`.

## 1. SQL (pgTAP)

`supabase/tests/database/creative-ranks.test.sql` доводить:

- перший `succeeded` Launch → +1; другий успіх того самого Launch → 0; `failed`/`canceled` → 0;
- 4 Launch пачкою → +4;
- каталог напряму → +1; каталог Launch-а + успіх Launch → +1 (обидва порядки подій);
- archive Launch не змінює ранг; заміна відео в каталозі не переносить подію;
- бекфіл двічі → ті самі числа;
- `demote` від не-owner → 42501; не нижче → PT409; стара версія → PT409; повтор ключа → той самий стан;
- `list_creative_ranks` чужого простору → 42501;
- (guard аналітики не змінюється: події користуються наявними ключами)

## 2. Unit (vitest, single-worker)

`tests/creative-ranks.test.ts`: `leagueOf` на межах 0/1/4/5/14/15/39/40, `freshnessOf` на 14/15/60/61 днях
і майбутній даті, `demotionTarget` для обох причин і Воску, парсер списку.
`tests/creative-rank-ui.test.tsx`: плитка з рангом / без рядка / з помилкою читання; детальний перегляд
owner vs editor; пониження → оптимістичний стан і конфлікт.

## 3. Бета (руками через драйвер)

1. Простір Goor, тестова папка. Відео без запусків → «Без рангу», «ще не запускали».
2. Згенерувати Launch для відео → в іншому вікні ≤ 5 с емблема «Віск», `1 запуск · сьогодні`.
3. Перегенерувати той самий Launch → без змін. Скопіювати Launch, згенерувати → `2×`.
4. Створити каталог з відео напряму → `3×`.
5. Детальний перегляд як owner → «Понизити ранг» → «Так і не запустив» → «Без рангу», `3 запуски` лишилось.
6. Як editor — кнопки немає.
7. Світла/темна тема, вузьке вікно, reduced motion — емблема не перекриває чекбокс і меню.
8. `npm run analytics -- creative-rank --team <id> --material <id>` пояснює кроки 2–5.

## 4. Гейти

`npm run verify` (CI-набір) — лише коли машина вільна і немає іншої сесії з важким процесом.
