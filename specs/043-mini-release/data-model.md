- **PrewriteAdmission**: exact isolated compatibility/role/data/agent proofs + exact production artifact/config proof; дозволяє лише declared compatible backend і candidate preview controls без production статичного deploy.
- **ActivationAdmission**: prewrite digest + fresh postapply surface state + exact production-config visible control + trusted static route-broker evidence; дозволяє web activation. NOT_RUN production-dependent control не підміняється isolated PASS.
- **SupportMatrix**: versioned platform/cohort/package/contract/capability/seam fingerprints, required checks та admissible reuse proof; explicit finite enrollment з signed baselines, [selector contract](contracts/support-matrix.md).
- **VendorLedgerTuple**: exact sourceDigest + pinned CLI/PG schema adapter + version/name/ordered statements generated official CLI during disposable rehearsal; production executor writes identical tuple atomically with its SQL, [history contract](contracts/migration-history.md).

## Execution and observations

- **ExecutorEvidence**: verification UID, exported-input/toolchain digest, filesystem ACL proof, effective PF ruleset/proxy digests, denied direct-egress canaries, private trust-context proof; fresh inputs bind admission, no env-only enforcement.
- **TargetClaim**: stable target root, run/task identity, process boot/start marker, generation/fencing nonce, delegated controller/worker ownership. Run-directory override не змінює lock namespace. Release лише власником; незрозумілий живий власник блокує takeover.
- **EffectReceipt**: run/attempt/step, target/binding/generation, request/candidate digests, preparedAt; observedAt, provider IDs, expected/actual observations; prepared → matching / proven-absent / conflicting / unknown. Timeout не є proven-absent. Міграційний batch має receipt на весь exact batch перед його запуском.
- **RunSnapshot**: чинні state/envelope fields плюс mode, operation, intentDigest, baselines, selectedStepIds, prewriteAdmissionDigest, activationAdmissionDigest, publication state і last proven stage. Чужі step IDs/order не приймаються; completed локально не означає still-current зовнішню ціль.
- **DeploymentReceipt**: confirmed web/functions/schema state, unchanged agent channel, previous baseline digest, epoch, observation refs, completed/partial/recovered. Finalize CAS не перезаписує сторонню новішу baseline. Partial deployment зберігає independent surface facts без загального succeeded.
- **DiagnosticProjection**: source freshness, latest proven stage, effect uncertainty, decision/recovery code, controls vs real attempts; production user identities тільки через existing permitted lookup, artifacts — непрямі IDs.

## State transitions

Selected mini stages: mini_preflight → mini_checks → mini_rehearse → mini_build → mini_verify → mini_backend_apply → mini_activation_verify → mini_deploy → mini_live_verify → mini_finalize. Непотрібний stage має explicit not-applicable receipt; він не виконує effect. Recover-web проходить admission/current-state checks, archive verification, exact deploy, live verification і finalize; new build/rehearsal/apply not-applicable із причиною.

Run states reuse draft/preflight/queued/running/waiting_resource/waiting_remote/reconciling/blocked/cancelling/cancelled/completed. Failure codes і publicationState розрізняють failed/partial/unknown без несумісної заміни existing state enum. Resume звіряє весь intent і journal, re-observes external dependencies; cancel припиняє нові writes, поточний незворотний effect reconciles. No automatic DB/web rollback.

## Retention and trust

Target store: 0700 directories, 0600 files, fsync before effects; canonical digests з schemaVersion. Зберігати останні 5 підтверджених distinct web artifacts плюс referenced active/recovery artifacts; journals/evidence 90 днів, active/unresolved runs не видаляти; expiry у report. Vendor bodies читаються лише у приватному temporary workspace, у report тільки hashes/closed codes. No production application rows, secrets, raw paths/provider payloads у export.
