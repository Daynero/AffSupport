# Research and decisions

## Джерела чинної поведінки

- `apps/web/src/team/catalog-updater/CatalogUpdaterDialog.tsx`: окремий інтервал у рядку, глобальні параметри змісту в footer; дата останнього успіху не показана.
- `apps/web/src/api/team.ts`: `CatalogRegistryRow` уже має `lastUpdatedAt`, `updateCount`, `lastUpdateError`, `updateInterval`, `nextRunAt`.
- `supabase/migrations/20260918120000_catalog_updater_grow.sql`: worker отримує глобальні `refresh_images`, `refresh_texts`, `grow_products` через `team_catalog_updaters`.
- `supabase/functions/catalog-updater/worker.ts`: claim, lease, три паралельні обробки, retry та переписування таблиці на місці.
- `apps/web/src/team/catalog-updater/useCatalogUpdater.ts`: 60-секундне загальне й 5-секундне активне опитування; старий список при помилці не позначається.

## R1 — профіль кожного каталогу

**Decision**: Зберігати окрему копію п’яти параметрів для кожного каталогу; шаблон простору використовувати лише при створенні нового каталогу. Міграція копіює чинні глобальні значення для наявних каталогів у транзакції.\
**Rationale**: Видимий ефективний профіль без прихованого успадкування; чинна поведінка зберігається.\
**Alternative**: Динамічне успадкування шаблону — зміна глобального значення могла б непомітно змінити сотні каталогів.

## R2 — доставка та ідемпотентність

**Decision**: Знімок профілю фіксується при claim; кожна спроба має ключ і стан етапів. Перед позначенням успіху перевіряються запис і доступність таблиці за незмінним посиланням. Після невизначеної відповіді від Drive повтор спершу звіряє фактичну версію/метадані й не нарощує товари вдруге. Видалення старого відео — лише після підтвердження нового посилання.\
**Rationale**: Безпека при timeout після фактичного запису.\
**Alternative**: Повторити весь worker від початку — ризик подвійного приросту й втрати відео.

## R3 — читання великого списку

**Decision**: Один підсумковий read-contract із версією/часом знімка, сторінками або віконним рендером та точковими змінами з чинного realtime seam. Пошук/фільтр виконується на сервері для сторінок або локально лише після завантаження повного обмеженого знімка; частковий набір не видається за всі збіги. Часте опитування — лише для активних спроб, з backoff; невдале оновлення позначає snapshot застарілим. Нативна прокрутка.\
**Rationale**: Керування не блокується прогресом і зайвими повними перечитуваннями.\
**Alternative**: 5-секундне повне перечитування 500 рядків — зайва мережа й стрибки scroll anchor.

## R4 — діагностика

**Decision**: Розширити типізовані сигнали спроб та інвентар покриття й додати read-only діагностику за catalog/attempt ID до наявного analytics CLI. Невідомий/запізнілий сигнал позначати явно.\
**Rationale**: Вимога `specs/031-platform-autoanalytics/spec.md` стосується всіх нових journey.\
**Alternative**: Лише UI toast або лише event — не дає агенту доказу доставки.
