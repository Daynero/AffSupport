# Research decisions

- Decision: one compact indexed pool of2,000 image-parameterized variants. Existing generator caps at1,000 and invents fabric/size/care statements. A40×50 index product guarantees exact size without random rejection; descriptions contain only supported image facts. A per-space DB pool duplicates data and adds maintenance without useful cost savings (local sample5,000pairs≈1.38MB/150ms).
- Decision: classify published images from their validated classification; use strict `classifyCatalogImageName` for legacy filenames. Substring-based `pictureFacts` can misclassify ambiguous names; unknown facts remain neutral.
- Decision: server insertion marker and versioned Launch source identity. Empty checkpoint is not proof of a new intent. Preserve the legacy hash and all old checkpoints; new standalone inserts and new automatic Launch revisions opt in without a public payload change.
- Decision: keep final durable row/sheet recipes authoritative. Seed alone cannot preserve output across future generator versions. Creation already has `rememberRowRecipe`/`rememberSheetRows`; updater unknown writes retain snapshots but proved-unchanged reconciliation deletes them, so a bounded active-round recipe must survive that retry.
- Decision: automatic updater content follows final image allocation. Global growth postpones image allocation until refresh; retained existing rows constrain image buckets, added rows do not inherit copied legacy text constraints. Retained text also retains price.
- Decision: remove runtime settings mounts and creation dependency rather than destroy historical modules/tables. This also removes the creation dialog's accidental import of the1,600-line settings component for a price constant. Old bookmarks open the surviving manager.
- Decision: retire the background text-generation invocation; retain historical diagnostics. A hidden schedule must not continue pointless regeneration.
- Decision: append safe policy/count projections to existing diagnostic views and use optional-column reads for older deployments. Fix the actual missing global-image error mappings and standalone catalog `inspect` join. Updater evidence belongs to immutable attempt receipts, never the current catalog snapshot.
- Decisions were checked against three read-only research passes (backend durability, UI removal, shared policy/diagnostics). No provider access, production changes or new dependencies were needed.
