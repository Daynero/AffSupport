# Feature Specification: Soty без агента — усе, що можна без нього, працює без нього

**Feature Branch**: `074-ideas-2026-11-24` (база `v1.7.2`)

**Created**: 2026-11-27

**Status**: Лише спека (рішення власника 2026-11-27: «3 в роботу, 2 спекою»). Інвентар — нижче; реалізація — окремим заходом.

**Input**: Сесія ідей власника 2026-11-24 (пункт 4 + мій 6.13), переказ:

> «Це, напевно, дуже велика зміна, але треба її провести. Треба, щоб простір працював без агента. А це значить, що в цілому Soty має працювати без агента. Але, звісно, не повноцінно: ти можеш заходити, передивлятися файли, менеджити акаунти, робити запуски, якщо без перезашивки умовно. Коротше, те, що можна зробити без агента, щоб можна було робити без агента.»
>
> Моя пропозиція (6.13): «черга дій без агента — поставив з телефона, виконалось, коли агент онлайн».

## Головна знахідка інвентаря

Простір **уже** не закритий агентом на рівні маршруту (`ProtectedSoty.tsx:101-112`, `/team` без гейту; провідник гейтиться лише станом Drive). Тобто «без агента» сьогодні майже все *можна*, але виглядає й поводиться так, ніби не можна:

- **(a)** чип «Підключіть Soty» і тон «увага» в стані простору горять завжди, коли агента нема (`AgentLinkChip.tsx:20-58`, `SpaceHealth.tsx:222-275`, `useSpaceHealth.ts:82-88`) — простір виглядає зламаним;
- **(b)** «Завантажити» й дії над виділенням активні, а падають лише після натискання: файл > 32 МіБ, контейнер, з якого браузер не вміє зняти метадані (WebM/MKV/AVI), `agentAvailability: 'ready'` захардкоджено (`ExplorerSelection.tsx:113`); дія `download` не має `needsAgent` (`materials/actions.ts:348`);
- **(c)** для файлів > 32 МіБ немає браузерного шляху взагалі (`drive-transfer/handler.ts:289-295` → `AGENT_REQUIRED`);
- **(d)** дві речі прив'язані до агента без потреби: повторне використання готового транскрипту (`explorer/useAgentQueue.ts:341`) і вибір папки для завантаження в Safari/Firefox (`useExplorerUploads.ts:490-500`, перетягування працює);
- **(e)** запуск або каталог з перезашивкою без агента мовчки «чекає агента» — людині не сказано, що він стане в чергу й виконається, коли Soty з'явиться.

## Користувацькі історії

### US1 — Простір без агента не виглядає зламаним (P1)

1. Без агента чип у шапці простору — нейтральний «Soty на цьому комп'ютері не запущено» з дією «Запустити / Встановити», а не тон помилки; стан простору (`SpaceHealth`) не переходить в «увагу» лише через відсутність агента.
2. Перший візит з телефона чи чужого комп'ютера — без онбординг-панелі встановлення поверх простору.

### US2 — Дії, яким агент потрібен, сказані до натискання (P1)

1. Кожна дія з реєстру (`materials/actions.ts`) має чесну ознаку: `browser` / `agent` / `browser-if-small`. Без агента дії `agent` показані вимкненими з підказкою «Потрібен Soty на цьому комп'ютері» і кнопкою «Встановити / Запустити»; дії `browser-if-small` перевіряють розмір і формат до натискання.
2. Виділення в провіднику рахує це заздалегідь: «3 з 5 файлів можна скачати тут, 2 — через Soty».

### US3 — Великі файли без агента (P2)

**[РІШЕННЯ, потребує заміру]** Браузерне скачування > 32 МіБ частинами (range-запитами по ≤ 32 МіБ, як уже роблять upload і preview) і збирання у файл через File System Access API (Chrome/Edge) або потоковий `Blob` для решти. Обмеження сервера знімається лише для `consumer='browser'` з range-запитами; метадані знімаються вікном латок, яке вже вміє `applyMediaMetadataPatchesToWindow` (073). Інцидент 2026-11-22 (обрізання на 32 МіБ) — причина нинішнього обмеження; без нового тесту на файлах 32–500 МіБ не вмикати.

### US4 — Робота, що чекає агента, сказана словами (P2)

1. Запуск із перезашивкою, каталог із відео, оновлювач з відео-варіантами без агента: «Стане в чергу і виконається, коли Soty на {комп'ютер фонової роботи} буде онлайн» — до створення, а не після.
2. На дошці — стан «чекає Soty» з назвою комп'ютера й часом останнього зв'язку.

### US5 — Черга дій з будь-якого пристрою (P3, моя ідея 6.13)

Перезашивка, стиснення, транскрибація, поставлені з телефона, ідуть у ту саму серверну чергу фонової роботи (делегування комп'ютера — уже є для каталогів), і виконуються комп'ютером фонової роботи. Обсяг — після US1–US4.

### US6 — Дрібні звільнення (P3)

1. Повторне використання готового транскрипту — серверний шлях без агента.
2. Вибір папки для завантаження — `<input webkitdirectory>` у браузерах без `showDirectoryPicker`.

## Термін

У коді «agents» означає дві різні речі: локальний застосунок Soty і рекламні агенти акаунтів (`add_team_account_agent`). У цій фічі «агент» = лише локальний Soty; у текстах інтерфейсу — «Soty на цьому комп'ютері».

## Межі

- Інструменти (компресор, стітчер, транскрибатор, оптимізатор лендингів) лишаються локальними.
- US3 — лише після окремого заміру; без нього обмеження 32 МіБ стоїть.
