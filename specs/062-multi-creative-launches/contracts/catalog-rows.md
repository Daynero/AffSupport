# Contract: рядки каталогу, ID і посилання

## ID товару (`supabase/functions/_shared/product-details.ts`)

```ts
catalogIdPrefix(name: string): string
// alias запуску: обрізка до 40.
// назва відео з провідника: без розширення → транслітерація укр. (КМУ 2010) →
// пробіли → '_' → прибрати все поза [A-Za-z0-9_-] → згорнути повтори _/- → trim _/- →
// обрізка до 40 → '' ⇒ 'creative'.

catalogProductId(prefix: string | null, unique = contentId()): string
// prefix ? `${prefix}-${unique}` : unique; довжина ≤ 100.
```

Тести: `^[A-Za-z0-9_-]{1,40}-[0-9A-Z]+-[0-9A-Z]{7}$` для нових; старий регулярний вираз — для каталогів без `_catalogRowCreatives`.

## Рядок за типом креативу

| Колонка | Відео без перезашивки | Відео з перезашивкою | Зображення |
|---|---|---|---|
| A id | `<prefix>-<unique>` | те саме | те саме |
| H image_link | біла картинка пулу | біла картинка пулу | URL креативу (`c1/<uuid>`) |
| Z video[0].url | оригінал свого відео + `?v=` | вихід своєї варіації | порожньо |
| AA video[0].tag[0] | випадковий тег | випадковий тег | порожньо |
| назва/опис/ціна | 055 за білою картинкою | 055 за білою картинкою | нейтральний 055, 20–40 |

## Порядок

Рядки йдуть блоками `segments[0]`, `segments[1]`, … ; у блоці `rowCount` рядків. Призначення варіацій усередині блоку — `createCatalogVideoAssignment` над підмножиною `recipeRowIds` блоку з зерном `hex(sha256(assignmentSeed ‖ ':' ‖ ordinal))` (детерміновано, зберігається в сегменті).

## Перевірки при записі

- Кожен рядок блоку зображення має `imageLink === _catalogCreatives[ordinal].url` і запис `launch_creative_images.state='ready'` цієї команди.
- Кожен рядок блоку відео має відеопосилання, що належить джерелу або набору свого сегмента.
- `Σ рядків блоку = rowCount`.
