# 064 · Приймання

## Передумови

- Локальна beta (`npm run beta:up` після `colima start`), реальна локальна авторизація, два простори з різними власниками, учасник без `manage_metadata`, адмін.
- Синтетичні дані: РК G1–G5, офер ProCaps із профілем (бюджет, 60 товарів), матеріали TR_16, TR_18, TR_25 (відео, країна Туреччина).
- Провайдер-підміна повертає задані плани, usage, затримку, помилку й обрив. Реальний провайдер — лише в T030 і на next.
- Керований час для північ/DST-сценаріїв.

Перевірки:

```sh
uptime                                     # один важкий процес за раз
npm run build -w @video-compressor/shared
npm run test:db                            # pgTAP
npx vitest run <файли задачі> --pool=forks --poolOptions.forks.singleFork=true
```

Повний `npm run verify` запускає CI. На слабкій машині — лише цільові тести.
