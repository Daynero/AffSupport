# 057 — Простори Soty на R2

Повний пакет проєктування, імплементацію не почато. Редакція 2026-11-27: переносу старих
просторів немає. План і задачі перераховано під три етапи.

- **M1.** Власник сам працює в R2-просторі на next. Решта користувачів і прод цього не помічають.
- **M2.** Входи без Drive і доказ швидкості проти Drive-бази.
- **M3.** Архів старих просторів, місткість у тарифі 034, резерв, діагностика, загальний запуск.
