# Quickstart: перевірка перекладу транскриптів

## Передумови

- Воркдерево `AffSupport-063`, гілка `063-transcript-translation`.
- Перед важким кроком — `uptime` і `pgrep -fl "tsc|vitest|vite build"`, бо машина тримає лише один важкий процес.
- Бета: `colima start` (за потреби), `npm run beta:up`.
  - Міграції 063 на беті накочуються через `psql` із записом у `schema_migrations`. `migration up` на беті заблоковано чужою версією.
  - Ніколи не робити `db reset`.
- Без ключа API: у локальному оточенні функцій `SOTY_TRANSLATION_PROVIDER=fake`. З ключем: власник ставить `ANTHROPIC_API_KEY` у секрети функцій прод-проєкту (`supabase secrets set ANTHROPIC_API_KEY=… --project-ref …`).

## Автоматичні перевірки

```bash
npm run build -w @video-compressor/shared
npx vitest run --pool=forks --poolOptions.forks.singleFork=true \
  tests/transcript-translation-shared.test.ts \
  tests/transcript-translate-function.test.ts \
  tests/claude-shared.test.ts \
  tests/transcript-translation-sql.test.ts \
  tests/translation-ui.test.tsx \
  tests/translation-retirement-surfaces.test.tsx tests/team-contract.test.ts
npm run verify
```

Очікувано зелене, зокрема:
- вилучення 046 (старий перекладач і далі відсутній);
- контракт кодів помилок;
- паркани дизайну.

## Сценарії на беті (Chrome, простір Goor → тестова папка)

1. **Переклад у просторі (US1)**: відео з транскриптом → «Перекласти» → українська.
   - До запуску видно вартість і залишок.
   - Плашка плавно доходить до 100%, і вікно перегляду відкривається на «Українська».
   - Перезавантажити сторінку — переклад на місці, ліміт зменшився рівно на вартість.
2. **Повтор без оплати (FR-006)**: ще раз «Перекласти» → українська. Видно «Уже перекладено → Відкрити», залишок не змінився.
3. **Кілька мов (US3)**: додати «Іспанська (Мексика)». Потім:
   - у вікні три вкладки, перемикання плавне;
   - «Копіювати» копіює вибраний варіант;
   - у бічній картці «Копіювати» відкриває вибір.
4. **Ліміт (US2)**: перекладати, доки залишок не стане меншим за вартість наступного. Кнопки «Перекласти» немає, пояснення з двома числами й часом оновлення.
5. **Закрити й відкрити (US5)**: запустити переклад, закрити вікно, відкрити. Плашка з поточним прогресом, далі готовий результат.
6. **Відмова/збій**: `SOTY_TRANSLATION_PROVIDER=fake-refuse` / `fake-down`. Плашка зі спокійним текстом, ліміт повернуто, «Спробувати ще раз» працює.
7. **Транскрибатор (US4)**: готовий текст → «+» → українська. Закрити й відкрити — переклад є. Експорт SRT перекладу має таймінги оригіналу.
8. **Аналітика (US6)**:
   - `npm run analytics -- ai-usage --period today --json` → кількість, вартість, відмови;
   - `npm run analytics -- investigate <email> --json` → спроба з кодом і етапом.

## Справжня модель (після ключа)

`TR_25.mp4` у тестовій папці → переклад українською. Порівняти з `scratchpad/tr25/v3-high-*.json`:
- «таблетка», а не «планшет»;
- «Джанан Каратай»;
- 25 рядків;
- вартість у `ai-usage` ≈ $0,002.
