# 064 · Контракт чарунок

Чарунки — спільна AI-валюта Soty для перекладу 063 і помічника запусків. Майбутня AI-функція підключається, коли має оцінку ціни до дії й записує фактичний usage.

## Одиниця й грант

- 1 чарунка = $0.001. Значення зберігається в серверній конфігурації (`ai_settings.credit_usd`) і в пілоті через інтерфейс не змінюється.
- У кожного користувача (auth ID) є денний грант — `ai_settings.base_daily_grant`, початково 100, або персональний `ai_credit_grants.daily_grant`.
- Доба — календарна доба Europe/Kyiv. Залишок не переноситься на наступну.
- Доступно сьогодні = грант(сьогодні) − Σ списань(сьогодні) + Σ повернень(сьогодні). Підвищення гранту діє одразу за цією самою формулою.

## Ціна дії

| Функція | Формула | Де видно |
| --- | --- | --- |
| Переклад 063 | ⌈`units` / 900 × `rate[мова]`⌉, мінімум 1, де `units` — довжина транскрипту в символах. Початково `rate = 1` для всіх мов | «Перекласти · N» у `TranslateLauncher`, в обох місцях перекладу |
| Репліка помічника | За таблицею `assistant_price_v1`: ≤ 1500 символів → 1, ≤ 4000 → 2 | «Надіслати · N» у полі помічника |
| Безкоштовно | Відкриття, набір, вибір варіанта, перегляд, «Запустити», «Скасувати», стан, повторна доставка, читання готового перекладу, приєднання до вже запущеного того самого перекладу | Кнопка без ціни |

Правила:
1. Ціну рахує спільна чиста функція в `packages/shared/src/ai/pricing.ts`. Її викликають веб для кнопки й сервер для перевірки. Таблиці й ставки мають версію.
2. Клієнт надсилає `expectedPrice` і `priceVersion`. Сервер перераховує. Якщо ціна не збігається, повертає `409 PRICE_CHANGED` з новою ціною, нічого не списує й нічого не викликає.
3. Списується рівно показана ціна. Фактичну вартість у USD Soty записує окремо для адміна. Якщо вона вища, різницю покриває Soty. Користувача заднім числом не дораховують.

## Списання й повернення

```
натискання → [транзакція: перевірити баланс доби та місячний стоп → записати debit(op_key, price)]
           → виклик Claude (без прихованих повторів SDK)
           → успіх: usage_event(op_key, токени, usd) · debit лишається
           → відома помилка: refund(op_key) одразу
           → невизначено: стан unknown → звірення (≤ 15 хв) → немає доставленого результату → refund(op_key)
```

- `ai_credit_ledger` має унікальний ключ `(user_id, op_key, kind)`. Повторний debit чи refund з тим самим ключем повертає наявний запис.
- Debit і перевірка балансу виконуються в одній транзакції з `pg_advisory_xact_lock` за `user_id`. Два паралельні натискання на останні чарунки не можуть обидва пройти.
- Refund повертає суму в ту саму київську добу, в якій було списання. Повернення після півночі вчорашнього дня до сьогоднішнього балансу не додає. Користувач нічого не втрачає, бо вчорашній грант усе одно згорів.
- Переклад 063 зберігає свій ключ роботи (джерело, версія транскрипту, мова). Другий користувач, що натиснув «Перекласти» на той самий запущений переклад, приєднується без списання. Платить той, чий debit пройшов першим. Особу платника, суму й квитанцію бачить лише він сам.

## Місячний бюджет

- `ai_budget_months(month, limit_usd)`, початково $100. Встановити ліміт нижче вже витраченого за місяць не можна (`BUDGET_BELOW_SPENT`).
- Місячний стоп: якщо Σ USD спроб місяця, включно з невизначеними за верхньою оцінкою, ≥ ліміту, нові debit повертають `429 AI_MONTH_EXHAUSTED`. Безкоштовні дії працюють.
- Зовнішній запобіжник: ключ API живе в окремому workspace Claude Console зі spend limit на рівні бюджету. Встановлює власник. Soty цим не керує, лише показує в адмінці нагадування звірити.

## Адмінка (`AiBudgetPanel`)

| Показник | Як рахується |
| --- | --- |
| Ліміт місяця | `ai_budget_months.limit_usd` |
| Витрачено | Σ `ai_usage_events.usd` за місяць. Позначка «оцінка», якщо USD обчислено з токенів за тарифом, а не з білінгу |
| За функціями | Те саме з групуванням за `feature` (`translation`, `assistant`) |
| Прогноз | (витрачено за повні дні / кількість повних днів) × днів місяця. Без повних днів — «недостатньо даних» |
| Найгірший випадок | Витрачено + Σ денних грантів користувачів, активних за 30 днів × `credit_usd` × днів, що лишилися, включно з сьогоднішнім |
| Покриття ціною | Σ списаних чарунок × `credit_usd` / Σ фактичних USD за функцією. Нижче 1 — ціни треба підняти |
| Невідомий usage | Кількість спроб без usage і їхня верхня оцінка |

Дії адміна (RPC з `public.is_admin()` і журналом `ai_admin_events`): ліміт місяця, базовий грант, персональний грант за поштою підтвердженого акаунта, увімкнення помічника для простору, глобальний вимикач помічника, вимикач перекладу. Якщо найгірший випадок перевищує ліміт, адмінка попереджає, але дію не блокує.

## Перехід 063

1. 064 перетворює облік 063: `ai_feature_allowances` замінює `ai_credit_grants` + `ai_credit_ledger`, а `ai_usage_events` лишається.
2. Перемикання відбувається на початку київської доби одним прапорцем `ai_settings.translation_billing = 'credits'`. Операції, розпочаті до нього, завершуються за резервом 063. Нові отримують ціну в чарунках.
3. Старий клієнт без `expectedPrice` отримує `426 CLIENT_UPGRADE` до виклику Claude. Готові переклади відкриваються як раніше.
4. Якщо 063 потрапить на прод раніше за 064, діє той самий одноразовий перехід. Тіньова фаза не потрібна, бо денний ліміт не накопичується.

## Перевірки

| Приклад | Очікування |
| --- | --- |
| Транскрипт 2300 символів, ставка 1 | Кнопка «Перекласти · 3» (⌈2.56⌉). Після успіху −3, фактичні ≈ $0.0020 записані окремо |
| Залишок 3, два паралельні «Надіслати · 2» | Один debit пройшов, другий отримав `INSUFFICIENT_CREDITS`. Залишок 1 в обох інтерфейсах |
| Помилка провайдера 529 | Refund одразу, залишок як до натискання. 0 повторів платного виклику |
| Обрив після відправки, доставку не підтверджено | Стан unknown. Після звірення без результату — refund. Із результатом — debit лишається й результат доступний |
| Грант 100 → 150 при витрачених 40 | Сьогодні 110, наступної доби 150 |
| Ліміт $100, за 10 повних днів із 30 витрачено $40 | Залишок $60, прогноз $120, перевищення $20 |
| Витрачено $100.0004 | `AI_MONTH_EXHAUSTED` для платних дій, «Запустити» працює |
| Debit о 23:59:58, refund о 00:00:03 | Повернення в учорашню добу. Сьогоднішній баланс = повний грант |
