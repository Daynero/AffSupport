# Soty Review Contracts

These contracts define the first-stage local review artifact:

- [review-catalog.md](./review-catalog.md) — stable URLs, surface/state coverage and demo actions.
- [isolation-boundary.md](./isolation-boundary.md) — imports, runtime capabilities, build and network boundary.
- [visual-system-and-approval.md](./visual-system-and-approval.md) — token use, accessibility evidence and written approval gate.

They are UI/review contracts, not backend APIs. No production protocol, database or release
contract changes in this phase.
